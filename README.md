# 5 de Oro

Web para seguir en vivo mis jugadas del 5 de Oro (Oro, sin Revancha).

- Mientras salen las 5 bolillas, solo se ven las jugadas que todavía tienen chance.
- Al salir las 5 y la bolilla extra, se ven las jugadas que ganaron y cuánto: Pozo de Oro, Pozo de Plata y los premios fijos de $ 9.000, $ 1.800, $ 450, $ 180 y $ 65.

Abrí `index.html` en el navegador, o activá GitHub Pages (Settings → Pages → rama `main`). Los datos se guardan en el navegador.
