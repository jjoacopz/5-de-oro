# 5 de Oro

Web para seguir en vivo mis jugadas del 5 de Oro: cargo mis jugadas, marco las bolillas que van saliendo (Oro y Revancha) y solo quedan a la vista las jugadas que todavía tienen chance.

Abrí `index.html` en el navegador, o activá GitHub Pages (Settings → Pages → rama `main`). Los datos se guardan en el navegador.
